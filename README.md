# OURS

只属于两个人的静态情侣网站，无账号、无服务器，部署在 GitHub Pages。

在线地址：https://hongkuanyu.github.io/ours/

## 已有功能

- 午夜私厨视觉与首屏餐盘动效
- 18 道默认菜谱、分类筛选和点单抽屉
- 自定义菜品、菜谱编辑和菜品照片
- 在一起天数、生日倒计时与愿望清单
- 回忆照片墙和情侣翻牌游戏
- 使用暗号解密的私人信件
- 可安装 PWA 与离线缓存

## 修改内容

打开 `config.js`：

- `relationshipStart`：在一起的日期
- `herName`：她的名字或昵称
- `birthday`：生日月、日
- `memories`：照片、标题、日期、地点和文字
- `wishes`：初始愿望
- `gamePairs`：翻牌游戏配对内容

## 替换照片

把真实照片放进 `assets/`，再修改 `config.js` 中的 `memories[].src`。

```js
{ src: 'assets/us-01.jpg', date: '2026.10.25', location: '我们的家', title: '今天', text: '今天也很好。' }
```

建议先把照片压缩到每张 1 MB 以内，保证手机加载速度。

## 隐私边界

GitHub Pages 是公开静态托管。`robots.txt` 和 `noindex` 只能减少搜索引擎收录，不等于访问权限控制。

- 不要放身份证、住址、账号密码或高风险隐私
- 知道网址的人仍然可以访问公开内容
- 私人信件使用 AES-GCM 加密，默认暗号可在 `make-secret.cjs` 中修改后重新生成
- 如果以后需要真正的私人相册，应改用带登录和服务端鉴权的方案

## 菜谱与自定义菜品

默认菜单包含 18 道菜，覆盖前菜、主菜、主食、甜点、饮品和小吃。每道菜都有食材、步骤、时间和口味说明。

在菜单区点击「＋ 自定义菜品」可以：

- 添加任意菜名、分类、价格和介绍
- 逐行填写食材与做法
- 上传菜品照片，页面会自动压缩
- 保存后直接加入点单
- 再次打开菜谱进行编辑或删除
- 自定义菜谱保存在当前浏览器的 localStorage
- 换设备或清除浏览器数据后不会自动同步

默认菜谱数据在 `config.js` 和 `menu-extra.js`，自定义菜谱不需要改代码。
